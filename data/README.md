# Veri Seti

Bu proje için kullanılan ham veri seti şu anda repoya dahil değildir.

Orijinal projede `archive.zip` dosyası içinde aşağıdaki üç CSV dosyası bulunuyordu:

- `player_predictions.csv` — 30.645 satır × 58 sütun
- `goalkeeper_predictions.csv` — 2.567 satır × 58 sütun
- `player_role_clusters.csv` — 11.273 satır × 18 sütun

Veri seti daha sonra bulunursa şu konuma eklenmelidir:

```text
data/archive.zip
```
